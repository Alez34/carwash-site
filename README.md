# Шаблон сайта автомойки

Адаптивный одностраничный сайт на HTML, CSS и JavaScript без сборщика и сторонних зависимостей. Включает каталог услуг, часы работы и контакты, форму предварительной заявки и устанавливаемое PWA.

> **Демонстрационный режим:** в проекте нет сервера, реального бронирования или отправки заявок. Форма проверяет введённые поля и показывает предварительный итог только в браузере. Данные не отправляются, не сохраняются и не подтверждают запись.

## Запуск

Откройте `index.html` в браузере, чтобы посмотреть страницу. Для проверки установки PWA и офлайн-режима нужен локальный HTTP-сервер или HTTPS: service worker не работает при открытии через `file://`.

Например, с установленным Python:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. В совместимом браузере воспользуйтесь кнопкой установки или пунктом установки в меню браузера. На iPhone/iPad откройте сайт в Safari и выберите «Поделиться» → «На экран Домой».

## Замена демонстрационных данных

В начале `app.js` отредактируйте:

- `BUSINESS` — название, телефон, адрес, график, интервал записи и URL карты;
- `SERVICES` — название услуги, описание, цена, длительность и значок.

Замените заголовок и метаописание в `index.html`, а `icon.svg` — на фирменную иконку. Услуги, расписание и контакты в текущей версии — только примеры, а не реальные сведения об автомойке.

`BUSINESS.mapUrl` — необязательная ссылка на карту, она открывается отдельно и не требует API-ключа. Для установки сайта на HTTPS-домене разместите все файлы в одном каталоге. При изменении офлайн-файлов увеличьте версию `CACHE_NAME` в `sw.js`.

## Перед настоящим запуском

Подключите backend/API, который проверяет доступность слотов и сохраняет бронирование, и только после этого добавляйте отправку формы и подтверждение реальной записи. Отдельно настройте обработку персональных данных и защиту от спама. Без такой интеграции страница намеренно не отправляет и не сохраняет заявки.

## Состав проекта

- `index.html` — структура страницы и форма;
- `styles.css` — оформление и адаптивная раскладка;
- `app.js` — демонстрационные данные, генерация расписания, валидация формы и установка PWA;
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA-метаданные, локальный офлайн-кеш и иконка.

Сайт не подключает внешние шрифты, аналитику, cookie или сторонние скрипты. Service worker кеширует только локальные ресурсы сайта.
