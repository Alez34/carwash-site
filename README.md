# Шаблон сайта автомойки

Адаптивный одностраничный сайт на HTML, CSS и JavaScript без сборщика и сторонних зависимостей. Обновлённая тема: тёмные поверхности, неоновые акценты, деликатные микроанимации и prefers-reduced-motion. На телефоне — компактные секции, закреплённая навигация и кнопка записи. Включает каталог услуг, часы работы и контакты, форму предварительной заявки и устанавливаемое PWA.

> **Запись через Telegram:** форма проверяет поля и подготавливает текст заявки. После нажатия «Открыть Telegram» он передаётся Telegram как черновик; посетитель сам должен нажать «Отправить». Сайт не отправляет сообщения, не сохраняет введённые данные, а переход в Telegram не подтверждает запись. Запись подтверждается только ответом владельца.

## Запуск

Откройте `index.html` в браузере, чтобы посмотреть страницу. Для проверки установки PWA и офлайн-режима нужен локальный HTTP-сервер или HTTPS: service worker не работает при открытии через `file://`.

Например, с установленным Python:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. В совместимом браузере воспользуйтесь кнопкой установки или пунктом установки в меню браузера. На iPhone/iPad откройте сайт в Safari и выберите «Поделиться» → «На экран Домой».

## Замена демонстрационных данных

В начале `app.js` отредактируйте:

- `BUSINESS` — название, телефон, адрес, график, интервал записи, URL карты и `telegramUsername` владельца (username без `@`);
- `SERVICES` — название услуги, описание, цена, длительность и значок.

Замените заголовок и метаописание в `index.html`, а `icon.svg` — на фирменную иконку. Услуги, расписание и контакты в текущей версии — только примеры, а не реальные сведения об автомойке. Hero использует переданный Mustang (`public/mustang.png`); файл `public/mustang-cutout.png` — версия этого же изображения с прозрачным фоном для аккуратной интеграции в неоновый фон.

`BUSINESS.mapUrl` — необязательная ссылка на карту, она открывается отдельно и не требует API-ключа. Для установки сайта на HTTPS-домене разместите все файлы в одном каталоге. При изменении офлайн-файлов увеличьте версию `CACHE_NAME` в `sw.js`.

## Перед настоящим запуском

Укажите действующий Telegram username владельца в `BUSINESS.telegramUsername` в `app.js`, заменив `YOUR_TELEGRAM_USERNAME`. На сайте данные не сохраняются; при открытии Telegram поля заявки становятся частью ссылки и текста черновика, а посетитель может проверить и отредактировать его до отправки. Отправка происходит только после нажатия посетителем «Отправить» в Telegram. Для автоматической отправки без действия посетителя, проверки доступности слотов или подтверждения записи понадобится отдельный backend/API.

## Состав проекта

- `index.html` — структура страницы и форма;
- `styles.css` — оформление и адаптивная раскладка;
- `app.js` — демонстрационные данные, генерация расписания, валидация формы, Telegram-черновик и установка PWA;
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA-метаданные, локальный офлайн-кеш и иконка.
- `public/mustang.png`, `public/mustang-cutout.png` — исходная фотография и подготовленный прозрачный вариант для hero.

Сайт не подключает внешние шрифты, аналитику, cookie или сторонние скрипты. Service worker кеширует только локальные ресурсы сайта.
